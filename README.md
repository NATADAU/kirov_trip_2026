# Киров · командировка 2026

Мобильный рабочий лендинг для поездки 29 сентября — 2 октября 2026 года.

Внутри:
- личный маршрут по дням;
- актуальные перелёты;
- адреса с быстрым переходом в Яндекс Карты;
- программа фестиваля 28–29 сентября;
- блок «Нужно уточнить»;
- локальные заметки, которые сохраняются в браузере телефона.
